## Vulnerabilities

### [Critical RCE Vulnerability Disclosed in PHP's Session Upload Progress Feature](https://threatcluster.io/cluster/critical-rce-vulnerability-disclosed-in-phps-session-upload--54df53e8)

CVE-2026-115560 is a critical unauthenticated remote code execution vulnerability in PHP's session extension, disclosed on November 19, 2026. It affects PHP versions 7.x and 8.0 to 8.4.x, specifically when the session.upload_progress feature is enabled along with a mismatch in serialization handlers. Attackers can exploit this vulnerability by injecting malicious serialized objects into session data, leading to remote code execution. The vulnerability requires specific preconditions: the server must have session.upload_progress.enabled set to 1, and the application must switch serialization handlers at runtime. No patch is currently available, and the official mitigation is to disable session.upload_progress. The vulnerability has a CVSS score of 9.2, indicating its critical nature. The exploit method involves a two-request attack during file uploads, allowing the attacker to maintain control over the session data. The issue has been acknowledged in multiple advisories, including a Debian LTS advisory that recommends keeping the feature disabled unless absolutely necessary.

### [ASUS Fixes Critical Hard-Coded Key Vulnerabilities in Control Center Express](https://threatcluster.io/cluster/asus-fixes-critical-hard-coded-key-vulnerabilities-in-contro-30f2df78)

ASUS has released Control Center Express v1.7.29 to address three critical vulnerabilities, including CVE-2026-114202, which has a CVSS score of 10.0. This flaw allows unauthenticated remote attackers to forge authentication tokens and gain administrative access without user interaction. Two additional vulnerabilities, CVE-2026-114204 and CVE-2026-114205, also involve hard-coded keys, enabling low-privileged users to forge session tokens and create admin accounts, respectively. All versions prior to v1.7.29 are affected. Users are advised to update to the latest version and verify their systems. The vulnerabilities were disclosed on November 18, 2026, with no reports of as of now. ASUS also patched other critical flaws in related products on the same day.

*2 sources · score 72 · CVE-2026-112115, CVE-2026-114202, CVE-2026-114204, CVE-2026-114205, CVE-2026-126574*

### [Critical Zero-Click Vulnerability in WinGet Exposed Microsoft Supply Chain](https://threatcluster.io/cluster/critical-zero-click-vulnerability-in-winget-exposed-microsof-8b3570fc)

Cycode discovered a critical zero-click supply chain vulnerability in Microsoft's WinGet, affecting over 1.4 billion devices. The vulnerability allowed an attacker to exploit an automated internal tool used by Microsoft moderators to obtain their GitHub Personal Access Token (PAT) without any interaction or phishing. By submitting a malicious pull request with a controlled URL, an attacker could trick the system into sending the moderator's credentials. This flaw has been patched, and there is no evidence of exploitation in the wild. The incident highlights the risks associated with automated processes in software supply chains, particularly in package registries.

*2 sources · score 70*

### [Critical Remote Code Execution Flaw in Drupal Installer Disclosed](https://threatcluster.io/cluster/critical-remote-code-execution-flaw-in-drupal-installer-disc-2da79938)

Drupal has announced a critical vulnerability, CVE-2026-132165, in its core installer that allows unauthenticated attackers to potentially reinstall a live site via install.php, leading to site takeover or remote code execution. This flaw affects all supported Drupal core versions prior to 10.6.22, 11.3.22, and 11.4.13. The vulnerability was disclosed in advisory SA-CORE-2026-017 on November 18, 2026, and patches are now available. The attack requires no authentication and can be executed remotely if the install.php file is accessible. While no exploitation has been reported in the wild, the risk remains significant due to the nature of the vulnerability. Drupal rates the flaw as critical at 18 out of 25 on its risk scale, citing that exploitation may require complex configurations. Users are urged to upgrade to the latest versions to mitigate risks.

*2 sources · score 70 · CVE-2026-132165, CVE-2026-9082*

### [Critical Ruby Vulnerability ruby2ßhell Exposes Remote Code Execution Risk](https://threatcluster.io/cluster/critical-ruby-vulnerability-ruby2ßhell-exposes-remote-code-e-3a562f46)

A critical vulnerability named ruby2ßhell has been discovered in Ruby versions that process the ß character, allowing potential remote code execution. The flaw affects applications using ISO-8859 or Windows-125x character sets and specific string manipulation functions, such as upcase and swapcase. Exploitation requires inputting a string with 21 or more ß characters, leading to a buffer overflow. The vulnerability impacts popular Ruby frameworks like Rails and Sinatra, as well as self-hosted applications such as GitLab and Mastodon. Ruby has released patched versions 3.3.14, 3.4.13, and 4.0.10 to address the issue. A proof-of-concept code is expected to be published in a week. No CVE number has been assigned yet, but a security advisory has been issued. Operators are urged to update their Ruby installations promptly to mitigate risks.

*2 sources · score 70 · Ruby2ßhell*

### [New Windows 11 Zero-Day Exploit Bypasses BitLocker via Narrator](https://threatcluster.io/cluster/new-windows-11-zero-day-exploit-bypasses-bitlocker-via-narra-d32a8561)

A newly disclosed zero-day vulnerability, named FastUnlock, allows physical access attackers to bypass the Windows 11 lock screen and execute code on BitLocker-encrypted machines. The exploit leverages a flaw in the Narrator screen reader, enabling attackers to access hidden settings and run programs from an USB stick. The researcher Chaotic Eclipse, also known as Nightmare-Eclipse, claims it took only five minutes to breach a fully encrypted Windows 11 26H2 system with the November 2026 patch installed. This vulnerability requires physical access and at least one user account linked to an online Microsoft account. As of now, no patch or CVE has been issued by Microsoft, and the exploit has not been confirmed to be in the wild. The researcher has not tested other Windows versions, including Windows 10. Security professionals are advised to monitor for updates and consider blocking Narrator as a temporary measure.

## Breaches

### [SBC Medical Group Cybersecurity Incidents Expose 1.6 Million Customer Records](https://threatcluster.io/cluster/sbc-medical-group-cybersecurity-incidents-expose-16-million--5e4d8b1d)

SBC Medical Group reported two cybersecurity incidents affecting its Japan-based operations, exposing sensitive information of approximately 1.6 million customers and 20,000 employees. The first incident involved unauthorized access to databases, discovered on November 16, 2026, which extracted personal data including names, contact details, and passwords. The second incident involved breaches of clinic administrator accounts on the Tribeau booking platform, affecting reservation and treatment information. The company has not confirmed the unauthorized access of electronic medical records. Investigations are ongoing, and no evidence of data misuse has been reported as of November 18, 2026.
