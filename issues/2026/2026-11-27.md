## Vulnerabilities

### [Broadcom patches critical VMware vCenter auth bypass flaws; one](https://threatcluster.io/cluster/broadcom-patches-critical-vmware-vcenter-auth-bypass-flaws-o-aea18cf1)

Broadcom disclosed VMware Security Advisory VMSA-2026-0009 on November 19, 2026, covering vulnerabilities in VMware vCenter, Tools, and SDDC Manager. CVE-2026-123890, a CVSS 9.8 authentication bypass in the VMware Directory Service, is listed in CISA's KEV catalog, which the verified record gives as 2026-11-20. Mandiant/Google Threat Intelligence confirmed in-the-wild exploitation by the state-linked actor ARMORY CASTLE (also tracked as UNC5221) as early as September 2026, and reports the actor used the BONESAW malware for post-exploitation. Rapid7 reports that an attacker with network access to an affected vCenter deployment can exploit CVE-2026-123890 without credentials to gain Administrator access; the flaw is reachable over RPC. Broadcom later disclosed CVE-2026-123903, also CVSS 9.8, reachable over LDAP, which the verified record shows as published 2026-11-26. Rapid7 states that a public proof-of-concept for CVE-2026-123903 exists and that it validated the authentication bypass, while no in-the-wild exploitation of that CVE had been reported as of its writing. Rapid7 recommends urgent remediation of exposed systems outside normal patching cycles. Mandiant reported that ARMORY CASTLE exploited two zero-days in the campaign.

*2 sources · score 90 · CVE-2026-123890, CVE-2026-123903, CVE-2026-124284, Armory Castle, UNC5221*

### [CVE-2026-106125: Unauthenticated RCE in Sneeit Framework WordPress Plugin up to 8.7](https://threatcluster.io/cluster/cve-2026-106125-unauthenticated-rce-in-sneeit-framework-word-0db155c4)

CVE-2026-106125 affects the Sneeit Framework plugin for WordPress in versions up to and including 8.7. The sneeit_compact_menu_mega_content AJAX action registers its callback handler on wp_ajax_nopriv_, passing an attacker-supplied 'callback' value into call_user_func() after only a function_exists() check. The single argument is also attacker-controlled via a JSON-decoded 'args' parameter. No authentication, capability check, nonce, or allow-list is enforced, so unauthenticated attackers can call arbitrary existing PHP/WordPress functions with controlled arguments. The CVE record lists the weakness as CWE-94 (Improper Control of Generation of Code) and the CVSS 3.1 vector as AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H. Bugshield and the CVE record both list version 8.8 as the fix, according to Wordfence data cited by Bugshield. The CVE record was published 2026-11-27. The sources do not report exploitation in the wild or public proof-of-concept code. Bugshield notes its entry describes a reported issue and does not establish whether any site has been compromised.

*2 sources · score 74 · CVE-2026-106125*

### [CVE-2017-20291: XXE flaw in Broadcom SiteMinder Federation Web Services, public PoC released](https://threatcluster.io/cluster/cve-2017-20291-xxe-flaw-in-broadcom-siteminder-federation-we-69a712c9)

A XML External Entity (XXE) injection vulnerability, tracked as CVE-2017-20291, affects the Federation Web Services component (/affwebservices/router/session) of Broadcom SiteMinder (CA Single Sign-On) Secure Proxy Server / Access Gateway R12.52 SP1 prior to R12.52 SP1 CR6. The flaw lies in the exposed Apache-SOAP RPC Router servlet, which accepts crafted SOAP requests containing external entity declarations. Rapid7 states successful exploitation could result in unauthorized disclosure of local files or sensitive data, server-side request forgery (SSRF), or denial of service. Rapid7 rates the CVE at CVSS 4.0 Base Score 8.7 (HIGH). The issue is resolved in R12.52 SP1 CR6 by removing the router servlet mapping so the endpoint returns HTTP 404; Rapid7 states R12.8 and R12.9 are not affected. Sploitus published a validated exploit entry on 2026-11-26 describing a lab-based proof of concept that reads local files via the XXE on a modelled vulnerable build and refuses the declaration on a modelled guarded build. The Sploitus write-up states its vulnerable behaviour is modelled from Broadcom article 460506 rather than tested against a production installation. No confirmed is reported in the articles.

*2 sources · score 67 · CVE-2017-20291*

## Threat actors and malware

### [Fake Google Sheets Chrome extension used to read Gmail for Remus stealer buyers](https://threatcluster.io/cluster/fake-google-sheets-chrome-extension-used-to-read-gmail-for-r-0ab16565)

Gen researchers report that the Gmail 'zero-day' advertised by Remus infostealer sellers is a malicious Chrome extension disguised as Google Sheets, not a Gmail vulnerability. Gen's analysis was published November 24, and Invoke RE independently traced the feature to the same extension. Remus developers began promoting the feature on underground forums on November 8, claiming it survived password changes and session revocation. Some Remus builds download a module that writes the extension into the victim's Chrome profile on Windows, enables Developer Mode, and restarts Chrome; Gen says the technique reuses methods published since 2015. The extension polls unread Gmail messages every minute for up to 10 signed-in accounts and sends sender, subject, body and victim address to a command-and-control server. Collection stops when the victim signs out or sessions are revoked, but the extension persists and can resume when the user signs back in on the infected machine. Google told Cybernews there is no Gmail or Google vulnerability involved. Hudson Rock questioned the developer and a self-described customer and said promotional material did not establish post-recovery access. CyberInsider reports the feature is sold in a $1,000-a-month tier. Remediation advice from Hudson Rock is to treat a hit as a full endpoint compromise and check Chrome for unpacked extensions and Developer Mode.

*2 sources · score 66 · Infostealer, Remus*
